# 🩺 DisconnectDoctor

**Stop guessing. Start understanding.**

DisconnectDoctor is a Minecraft mod that makes confusing errors easier to understand by translating complicated technical messages into simple, beginner-friendly explanations.

Instead of staring at endless Java exceptions, DisconnectDoctor helps you understand what went wrong and what you can do about it.

## ✨ Features

- **Simple Error Explanations** – Understand what Minecraft errors actually mean.
- **Crash Report Analysis** – Get explanations of confusing crash reports.
- **Connection Error Explanations** – Understand why you got disconnected.
- **Mod Conflict Detection** – Identify possible incompatibilities between mods.
- **Missing Dependency Explanations** – Understand which dependencies are missing.
- **Troubleshooting Tips** – Get possible solutions to common problems.

## 🔧 Compatibility

- **Minecraft Version:** 1.21.11
- **Mod Loader:** Fabric

## 📦 Installation

1. Download the latest release.
2. Make sure you have Fabric installed.
3. Place the mod JAR file into your Minecraft `mods` folder.
4. Launch Minecraft.

## 💜 Our Goal

Make Minecraft errors understandable for everyone, whether you're a beginner or an experienced modder.
